# Austin Sorreta — Personal Portfolio

A responsive personal portfolio introducing Austin Sorreta, an Information Technology student interested in web development, interface design, and digital art.

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript

## Features

- Home, About, Skills, Tech Stack, Projects, and Contact sections
- Student-focused About, education, academic experience, and internship-ready contact copy
- Responsive navigation menu
- Dark and light theme toggle with saved preference
- Figma-inspired responsive styling across the portfolio and project pages
- Scroll-driven horizontal sliders for Skills, Tech Stack, and Projects, with individually zooming cards and side previews
- Clickable project cards featuring Austin's portfolio, Campus Connect interface, Student Planner, Calendar, and Calculator
- Separate Skills category cards and individual Tech Stack cards for each language and tool
- Original HTML, CSS, and JavaScript implementations for the interactive project pages, with Campus Connect designed in Figma
- Contact form that prepares an email draft
- Reduced-motion support and keyboard focus styles

## Run locally

Open `index.html` in a browser. Project pages in `projects/` are built with HTML, CSS, and JavaScript; Campus Connect is also designed in Figma. The Google Fonts and Font Awesome icons require an internet connection; the portfolio content and styles are stored in this repository.

## Publish

The source is ready for a static host such as GitHub Pages, Netlify, or Vercel. No public repository or live deployment is configured in this local workspace yet. After publishing the source to a public repository, enable a static-site deployment and test the public URL on desktop and mobile before submitting.
